

# Especificación de Requerimientos No Funcionales — Proyecto “inspira-T”

## 1. Usabilidad y Accesibilidad
* **RNF-01:** Interfaz inclusiva para adultos mayores (fuentes ≥12pt, alto contraste y botones amplios).
* **RNF-02:** Lenguaje e iconografía intuitiva, libre de jerga técnica.

## 2. Rendimiento y Eficiencia
* **RNF-03:** Consumo bajo de recursos de hardware (RAM < 350 MB, CPU < 15%).
* **RNF-04:** Tiempos de respuesta de la interfaz y consultas en BD inferiores a 2 segundos.
* **RNF-05:** Carga y reproducción fluida de cápsulas multimedia en un máximo de 3 segundos.

## 3. Compatibilidad y Portabilidad
* **RNF-06:** Multiplataforma en Java JRE 17+ (Windows, macOS y Linux).
* **RNF-07:** Empaquetado ejecutable e independiente de fácil instalación.

## 4. Fiabilidad y Mantenibilidad
* **RNF-08:** Captura y manejo de excepciones Java para evitar cierres forzados.
* **RNF-09:** Integridad referencial y persistencia segura en la BD Relacional.
* **RNF-10:** Código modular bajo control de versiones (Git) para futuras actualizaciones.
